# Avro ↔ Bijoy Bangla Converter

**Live website:** https://converter.iamnasim.com/  
**Developer:** Nasim Bin Jasim

A free, responsive web tool for converting Bangla text between **Unicode (Avro)** and **Bijoy ANSI** formats. It is designed to make Bengali text conversion simple for everyday writing, office documents, and other workflows that require either format.

## Features

- **Two-way conversion:** Convert Unicode (Avro) text to Bijoy ANSI and Bijoy ANSI text back to Unicode.
- **Copy with one click:** Copy converted text to the clipboard.
- **Download converted text:** Download the conversion result.
- **File upload:** Upload `.txt` files for conversion (up to 5 MB).
- **Conversion history:** View recent conversions. Up to 10 conversions are stored locally in the browser.
- **Offline mode:** Use the converter offline where the site's offline support is available.
- **Responsive interface:** Designed for use on desktop and mobile devices.
- **Format switching:** Switch between Avro/Unicode and Bijoy conversion directions.
- **Simple Bengali interface:** Controls and guidance are presented in Bengali.

## How to Use

1. Open https://converter.iamnasim.com/.
2. Select **Avro → Bijoy** or **Bijoy → Avro**.
3. Paste or type Bengali text into the input area, or upload a supported `.txt` file.
4. Click **Convert**.
5. Review the converted text in the output area.
6. Copy the result or download it for later use.

### Important note about Bijoy text

Bijoy ANSI text may look like Latin characters in applications that do not use a compatible Bijoy font. To display it correctly, apply a compatible font such as **SutonnyMJ** in the destination application. Unicode text is generally the better choice for websites, email, and modern applications.

## Conversion History and Privacy

The website indicates that up to 10 recent conversions are stored in local browser storage. If you use a shared computer, clear the site's history or browser data when appropriate.

## Offline Use

The interface includes an **Offline Mode** option. Availability may depend on having opened the website while online and on browser support. For best results, open the site once with an internet connection before trying offline use.
